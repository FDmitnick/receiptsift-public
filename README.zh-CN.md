# ReceiptSift PDF

一个英文优先、可追溯原文位置的 PDF 账单与收据解析工具，包含公开 SEO 站点和受保护的私测工作区。

[官方网站](https://www.receiptsift.example/) · [English README](./README.md) · [API 文档](./docs/API.md) · [架构](./docs/ARCHITECTURE.md) · [50 份评测](./docs/EVALUATION.md) · [隐私](./docs/PRIVACY.md)

ReceiptSift 可以真实读取文字型与扫描型 PDF，提取商户、日期、收据编号、币种、小计、税费、小费、总额、支付方式和商品明细。单份与批量结果都会加密保留最多 7 天以便复核；用户还可以明确确认，把结构化字段和行项目沉淀到不含原始 PDF 的长期台账。

## 当前已经可用的功能

- PDF 签名、大小、页数和加密状态校验
- PyMuPDF 文字层提取
- RapidOCR + ONNX Runtime 服务内扫描件 OCR
- 中英文票据标签识别
- Atlas 主模型、请求故障备用模型、确定性质量门与条件式 GPT 独立复核
- 字段置信度、原文内容和归一化坐标
- 点击字段定位第一页原文
- 字段与商品明细在当前浏览器页面内编辑、应用和撤销
- 浏览器内 CSV 导出，离开或刷新前明确提醒
- 批量工作台：多 PDF 上传、真实进度、重复提示、异常审核、重试和统一 CSV
- 批次状态可接 PostgreSQL，原 PDF 应用层加密后写入私有 S3 兼容存储，支持独立 Worker
- 默认英文、中英文即时切换
- 公开 SEO 首页、隐私说明、条款、robots 和 sitemap
- 邮箱账号、Argon2id 密码哈希和邮箱验证注册
- Resend 邮箱验证与单次密码重置链接
- 独立账号、套餐、汇总用量统计、账户数据导出和账户删除
- 不含凭证内容的解析订单账本，记录输入/输出摘要、解析器版本、状态、耗时和置信度
- 用户主动授权的错误诊断报告，材料加密保存最多 14 天，并支持提前删除
- 删除账户前自动取消非终态 PayPal 订阅；取消失败则保留账户数据
- 单一所有者运营后台：用户、用量、访问转化、付款、人工退款、取消订阅和审计记录
- 需用户同意的第一方访问/重点点击统计，不保存原始 IP、浏览器指纹或票据内容
- 账号会话保护的工具、账单 API 与 `/api/docs`
- 解析器与完整 API 生命周期测试
- 私有 50 份账单全流程评测、断点续跑、逐模型 token/成本统计与错例回归

## 隐私边界

- 普通解析的原 PDF、预览、提取结果和修改内容会加密保留最多 7 天，也可以提前删除。
- 普通解析的结构化结果、提取文本、修改、文件名与预览都不会由应用持久保存。
- 当前结果只存在于浏览器页面内存，离开或刷新后无法恢复。
- 单份解析与批量工作台统一采用最近 7 天加密历史：原 PDF、预览、结构化结果与修正最多保留 7 天，用户可提前删除；经用户确认的结构化字段和行项目可沉淀到长期台账，但不会复制原 PDF。
- OCR 在 ReceiptSift 服务进程内运行，不发送到第三方 OCR API。
- Atlas 模式会把渲染页发送给 Atlas 及其底层模型；质量门失败时还可能发送给配置的 GPT 复核模型。
- 托管模式下，解析工具、账户后台和 API 文档都需要签名账号会话。
- SQLite 保存账户、计费、安全、汇总用量和不含凭证内容的订单技术元数据。
- 只有用户主动勾选授权并提交“结果有误”报告时，诊断描述、原始结果、当前修改和上传 PDF 才会使用专用密钥加密保存，最多 14 天，且可在账户页提前删除。密钥缺失或错误时功能会关闭，不会降级为明文。
- 托管注册只有在事务邮件与公开站点地址配置完成后才会开放。

详细规则见 [docs/PRIVACY.md](./docs/PRIVACY.md)。

## 运营后台

在部署环境设置 `RECEIPTSIFT_ADMIN_EMAIL=contact@example.invalid`。该邮箱必须先注册并完成验证，然后使用此账号登录并打开 `/admin`。其他登录用户访问后台页面会得到 `404`，访问后台 API 会得到 `403`；环境变量留空时运营后台对所有账号关闭。退款与取消订阅均由所有者手工操作，并要求确认词和审计记录。

## Windows 快速启动

需要 Python 3.11 或以上版本。

```powershell
git clone <你的仓库地址>
cd receipt-parser-prototype
.\run.ps1
```

打开 <http://127.0.0.1:4317/>。第一次运行会自动创建 `.venv` 并安装依赖。

以后可以跳过依赖检查：

```powershell
.\run.ps1 -SkipInstall
```

macOS / Linux：

```bash
chmod +x run.sh
./run.sh
```

## 当前边界

这是一个可工作的账号隔离私测版，但还不是完整的商业身份系统：

- 提取逻辑是确定性的规则系统，非常规版式可能需要人工修改。
- 目前只可视化第一页，但所有页面都会参与文字和字段提取。
- 不支持有密码的 PDF。
- 还没有 MFA、分布式登录限流、团队角色和组织工作区。账户、计费与解析订单仓库仍使用 SQLite，全部水平扩展前还需迁移。运营后台目前故意只支持一个环境变量指定的所有者。
- 置信度只是核对提示，不是会计或法律保证。
- 用于报销、记账或税务前必须人工复核。

完整接口、架构与扩展说明位于 [`docs/`](./docs/)。
